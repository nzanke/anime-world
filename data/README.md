# 基礎データについて

このフォルダのデータ（works.tsv・staff.tsv.gz・episodes.tsv.gz）は、日本語版ウィキペディアの各テレビアニメの記事（作品情報の枠・スタッフ欄・各話リスト）から取り出し、加工したものです。取得日は meta.txt。

- ライセンス：クリエイティブ・コモンズ 表示-継承 4.0 国際（CC BY-SA 4.0） https://creativecommons.org/licenses/by-sa/4.0/deed.ja
- 著作者：日本語版ウィキペディアの各記事の執筆者（各記事の履歴を参照）。記事名は works.tsv の article 列。
- 加工：役職名の統一と区分け、人名の表記ゆれ・変名の統合、東映動画の番組で絵コンテの記載がない回に演出の担当者を入れたこと、制作会社の表記の分割など。

このフォルダの外にある評論（content/reviews/）は CC BY-SA 4.0 の対象ではありません。
