# アニメ評論資料室（サイトの元）

テレビアニメの番組ごとに、自分の評論と、ほかの書き手の評論・記事へのリンクをまとめる静的サイト。
`main` に変更を入れると GitHub Actions が `build.py` を動かし、GitHub Pages に公開する（初回だけ Settings → Pages → Source を「GitHub Actions」にする）。

## 書き足すところ
| ファイル | 中身 |
|---|---|
| `content/reviews/*.md` | 自分の評論。1本1ファイル。書き方は `content/reviews/_見本.md`（名前が _ で始まるファイルは公開されない） |
| `content/links.csv` | 他人の評論・インタビュー・記事。列：番組ID, 番組名, 種別, 題名, 筆者, 媒体, 日付, URL, 抜粋・メモ |
| `content/site.txt` | サイト名・説明 |
| `content/about.md` | 「このサイトについて」 |

- 番組ID は番組ページの URL の `w/〇〇.html` の〇〇（例 `w20-968`）。番組ID を空にして番組名だけでもよい（同じ名前が複数あるときは組み立て時に「注意」が出る）。
- 種別は「評論・批評・インタビュー・対談・記事・コラム・感想・資料」の順に並ぶ（ほかの言葉も使える）。日付は 2026-11-05 の形。
- 本文：1行が1段落。`## 小見出し`、`> 引用`、`- 箇条書き`、`[文字](URL)`、`[[番組名]]`・`[[番組ID]]`・`[[人の名前]]` でサイト内リンク。

## 基礎データ
`data/` は非公開の anime-database から `python3 tools/hyoron/export.py <このリポジトリ>/data` で書き出したもの（テレビアニメのみ）。データベースを直したら書き出し直してコミットする。

## 手元で確かめる
`python3 build.py` → `_site/index.html` を開く（標準ライブラリだけで動く）。
